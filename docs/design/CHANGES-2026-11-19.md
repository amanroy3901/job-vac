## 6. Data / API needs implied (for the architecture agent)

- Auth: Google ID token → Firebase Google provider; link to guest UID; merge semantics unchanged. Remove phone/OTP
  endpoints and phone fields; account shows `google_email` only.
- `ReferenceBundle.languages[] {code, status}`; user `lang` accepts the 13 codes.
- `privacy_notice_ack {version, at}` on the profile/account; Remote Config `notice_version`.
- Family: invite create `{relation, nickname?}` → `{invite_id, token, url, expires_at}`; accept by token (guest UID +
  FCM token); list followers (aspirant) and following (member); remove from either side; Pro-lapse pause.
- Push payload for `family`: `family_link_id`, `aspirant_name`, `stage`, `match_id`/`application_id` not exposed to
  the member beyond the job short title.
- Billing: Play only; `obfuscatedAccountId` = hash of UID; restore by Play purchase history for guests.
- Remove WhatsApp consent purpose and SMS/OTP DLT config; Consent purposes left: `ads_personalisation` (reserved).
- Android: `supportsRtl=true`, `locales_config` = enabled locales only, Auto Backup excludes auth/database.
