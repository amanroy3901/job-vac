# Contract alignment (design ↔ API ↔ backend ↔ frontend)

Date: 2026-11-19. Scope: every screen ↔ route ↔ endpoint, every notification type ↔ channel ↔ payload field, and
every shared enum across [`design/`](design/), [`api/`](api/), [`backend/`](backend/) and [`frontend/`](frontend/).
[`PRD.md`](PRD.md) decides scope; nothing below adds scope beyond it. P1/P2 items are given a contract shape or
explicitly deferred.

Validation after the edits: `openapi.yaml` passes `openapi-spec-validator` (OpenAPI 3.1, 50 paths); `schema.sql`
applies cleanly to an empty PostgreSQL 16 database; both `backend/examples/*.rule.json` validate against
`rule.schema.json`; the prototype's group A was re-rendered with Playwright (same 1640 px viewport, `#gA` element
screenshot) after the one visible copy change (#20).

## Canonical decisions this pass fixed

| Topic | Canonical value |
| --- | --- |
| Identifiers | `notice_id` `n_…` (advertisement, shared) · `post_id` `p_…` (one post = "the job", shared) · `match_id` `m_…` (user × post, private) · `application_id` `a_…` (user's tracked application) · `event_id` `e_…` (lifecycle event). Design `jobId` = `match_id`. |
| Links | `https://sarkarimatch.in/j/{match_id}` (push/WhatsApp) · `/p/{post_id}` (shared with another person) · `/a/{application_id}` (timeline) · `/f/{token}` · `/pro` · `/go/{match_id}` (web-only redirect to the official apply site) · `sarkarimatch://job/{match_id}` (push content intent). |
| Android channels (immutable) | `critical`, `new_match`, `reminders`, `job_updates`, `digest`, `account` (design 05 §1). |
| Push `type` | `match_new, reminder, deadline, extension, corrigendum, cancelled, lifecycle, digest, clash, certificate, account, self_test, ping, sync`. |
| Reminder slots | R0 `new_match` · Rp `periodic` · R3 `d_minus_3` · R1 `d_minus_1` · R-last `last_day` (+ `snooze_due`, `extension`, `corrigendum`); id `r:{match_id}:{kind}:{YYYYMMDD IST}`; cap ranks 1 R-last, 2 R1, 3 critical lifecycle, 4 new/extension/corrigendum/cancelled, 5 R3/snooze due, 6 Rp. |
| Trial | Offered at the first Applied (`paywall.variant=trial_offer`), started only by the user's tap (`POST /v1/me/trial`), 14 days from the tap. |
| Snooze | ≥ 4 days left: `tomorrow` (09:00) · `two_days_before_last_date` (L−2 09:00). 2–3 days left: `tomorrow` · `today_evening` (19:00). ≤ 1 day: none. |
| Not-interested reasons | multi-select `not_interested_reasons[]`: `not_interested_in_post, location, not_prepared, already_employed, not_eligible, other`. |
