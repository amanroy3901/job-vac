# Idea: Personalized notifications & reminders for government-job aspirants

## Raw idea (from founder)
"Give personalized notifications and reminders for a candidate preparing for a govt job. We can plan more features, but this is the basic idea."

## Working interpretation (assumptions — to be confirmed with founder)
- **Market:** India. Aspirants for central/state government exams — SSC (CGL, CHSL, MTS, GD), UPSC (CSE, CDS, NDA), Banking (IBPS PO/Clerk, SBI), Railways (RRB NTPC, Group D, ALP), Defence, Teaching (CTET/TET), State PSCs and state police.
- **Core job-to-be-done:** "Don't let me miss anything that matters for MY target exams" — never miss a notification release, application window, fee deadline, admit card, exam date, answer key, result, or cut-off — filtered to the user's eligibility (age, education, category, state, domicile) and chosen exams.
- **Personalization layer:** user profile (DOB, qualification, category, state, target exams) → only relevant alerts, eligibility check, age-limit countdowns, exam countdown.
- **Reminder layer (prep side, to be expanded):** daily study reminders/streaks, revision schedule, mock-test reminders, current-affairs nudges.
- **Platform:** Android-first app (repo `.gitignore` is an Android/Kotlin template). Push notifications as the core surface; possibly WhatsApp/Telegram later.
- **Founder profile:** not yet captured (no `user_profile.md`). Treat as solo indie Android developer, "builder" tier, until confirmed.
